# 现代 Transformer 核心架构与张量算子工程

## 归一化拓扑与硬件算术强度优化

### 归一化拓扑位置与残差动力学

* **残差前置归一化（Pre-Layer Normalization，Pre-Norm）**

    * > **定义**：将归一化算子置于多头自注意力机制与前馈网络计算分支之前、保持主干残差流未经归一化直接贯通的数据流拓扑结构。

    * 结构机理：单层传递公式为 $`x_{l+1} = x_l + F(\text{Norm}(x_l))`$，向深层展开为 $`x_L = x_l + \sum_{k=l}^{L-1} F(\text{Norm}(x_k))`$。

    * 梯度直通性：反向传播梯度满足 $`\frac{\partial \mathcal{L}}{\partial x_l} = \frac{\partial \mathcal{L}}{\partial x_L} \left( I + \frac{\partial}{\partial x_l} \sum_{k=l}^{L-1} F(\text{Norm}(x_k)) \right)`$，单位矩阵 $`I`$ 构成常数级无阻碍梯度直通高速路（Highway），提供直接梯度路径，通常改善深层优化，但单位阵项不保证总雅可比有界，也不能杜绝梯度衰减或爆炸。

    * 优化边界：虽然大幅稳定了深层训练并压抑梯度尖峰频率，但在千亿参数规模模型中仍无法完全省去学习率预热（Warmup）阶段。

* **残差后置归一化（Post-Layer Normalization，Post-Norm）**

    * > **定义**：将归一化算子直接置于计算分支与残差相加之后、直接拦截并改变主干残差流统计特性的原始拓扑结构。

    * 结构机理：单层传递公式为 $`x_{l+1} = \text{Norm}(x_l + F(x_l))`$，主干状态在每一层均被强制施加一次统计归一化。

    * 数值稳定性缺陷：反向传播链条中必须连续相乘每一层归一化算子的雅可比矩阵，导致反向梯度范数随深度加深发生严重非线性扭曲，深层训练极易爆发高频高幅梯度尖峰并诱发数值发散。

    * 架构例外：OPT-350M 使用 Post-LN；课程以此说明模型存在例外，并未证明这一选择导致该模型扩展失败。

* **纯净残差流（Clean Residual Stream）**

    * > **定义**：在深层网络主干残差路径上不设置任何非线性变换、特征缩放或统计归一化算子，确保浅层表征与顶层损失梯度均能实现无损穿透的架构准则。

    * 拓扑要求：所有参数化投影、非线性激活与统计规约操作必须严格限制在并行的侧分支内部完成，分支增量直接以线性加法并入主干。

* **外部后置归一化与双重归一化（External Post-Norm & Double Norm）**

    * > **定义**：在不截断主干残差流的前提下，将归一化算子移至计算分支输出端，或在分支输入端与输出端同时挂载归一化算子的防御型拓扑变体。

    * 外部后置归一化机制：特征输入直接进入注意力和前馈分支，在计算完成后对分支增量执行归一化，再将归一化后的输出累加回残差主干；典型代表包括 Grok、Gemma 2 与 OLMo 2。

    * 双重归一化机制：在注意力与前馈分支的输入端与输出端各串联一个归一化算子，形成双重防线。

    * 工程干预规则：在深层模型遭遇难以定位的损失震荡或数值异常时，在分支两端或子层内部增加归一化算子是立竿见影平抑数值波动的通用工程手段。

| 归一化位置         | 计算分支与残差合并顺序                                | 残差主干                              |
| :----------------- | :---------------------------------------------------- | :------------------------------------ |
| Post-Norm          | $`x`$ → Attention / FFN → 与 $`x`$ 相加 → Norm → 输出 | 相加后的主干经过 Norm                 |
| Pre-Norm           | $`x`$ → Norm → 计算分支 → 与 $`x`$ 相加 → 输出        | 残差跳连绕过 Norm 和计算分支          |
| External Post-Norm | $`x`$ → 计算分支 → Norm → 与 $`x`$ 相加 → 输出        | Norm 位于分支末端，残差跳连绕过该分支 |

### 归一化算子演进与算术强度瓶颈

* **均方根层归一化（Root Mean Square Layer Normalization，RMSNorm）**

    * > **定义**：舍弃均值统计、减法中心化操作与可学习偏置项，仅利用激活值均方根对特征向量进行缩放归一化的轻量级层归一化算子。

    * 数学算式：

      $`\displaystyle \text{RMS}(x) = \sqrt{\frac{1}{d} \sum_{i=1}^d x_i^2 + \epsilon}, \quad \text{RMSNorm}(x) = \frac{x}{\text{RMS}(x)} \odot \gamma`$

      其中 $`d`$ 为隐藏层维度，$`\gamma`$ 为可学习缩放参数向量，$`\epsilon`$ 为防止除以零的数值保护常数。

    * 表征效果：课程引用的消融中 RMSNorm 可达到与 LayerNorm 相近或更好的效果；不能保证任意配方完全无精度损失，稳定性和性能均需实测。

    * 行业收敛：成为 LLaMA 家族、Mistral、Qwen、Gemma 等现代主流开源及闭源大模型的通用基础配置。

* **标准层归一化（Layer Normalization，LN）**

    * > **定义**：在特征维度上同时统计均值与方差，进行减均值中心化、除以标准差缩放，并挂载可学习缩放与偏置仿射变换的经典归一化算子。

    * 数学算式：

      $`\displaystyle \mu = \frac{1}{d} \sum_{i=1}^d x_i, \quad \sigma^2 = \frac{1}{d} \sum_{i=1}^d (x_i - \mu)^2, \quad \text{LN}(x) = \frac{x - \mu}{\sqrt{\sigma^2 + \epsilon}} \odot \gamma + \beta`$

    * 统计特性：具备平移不变性与缩放不变性，自由度严格高于 RMSNorm，但在自回归语言建模任务中额外的平移自由度并未转化为建模性能收益。

* **算术强度（Arithmetic Intensity）**

    * > **定义**：计算任务在硬件上执行时，所完成的浮点运算次数（FLOPs）与必须在不同级内存间搬运的数据字节数（Memory Access Bytes）的比值，单位为 $`\text{FLOPs}/\text{Byte}`$。

    * 硬件特征对比：
      * 矩阵乘法（GEMM）：算术强度极高，数据载入片上高速缓存（SRAM）后被高倍重复利用，处于算力受限（Compute-Bound）状态，GPU 计算核心高负载运转。
      * 统计归一化（Norm）：算术强度极低，必须在全维度上对庞大激活张量执行规约与逐元素访存，处于内存带宽受限（Memory-Bound）状态，GPU 计算单元因等待显存（HBM）传输而处于饥饿空转。

    * 耗时分布反差：归一化运算仅占据模型前向与反向传播总 FLOPs 的约 0.17%，但因低算术强度导致的显存读写瓶颈，课程引用的特定 profiling 案例中约占 25% 时间；该比例不能推广到任意模型、内核与硬件。

    * RMSNorm 优化：减少均值统计及相关操作；实际访存次数与加速幅度依赖融合内核。它改变了归一化函数，并非对 LayerNorm 的严格等价改写。

* **无偏置线性层（Bias-Free Linear Layers）**

    * > **定义**：彻底剥离 Transformer 内部所有线性投影算子（Q/K/V 投影、输出投影及前馈层投影）中的加性可学习偏置向量 $`b`$ 的网络实现方案。

    * 数学算式：前向映射严格表示为 $`y = xW`$。

    * 算子融合优势：偏置相加属于算术强度极低的内存读写密集操作，剔除偏置后显著简化了矩阵乘法底层的算子融合（Kernel Fusion），提高了 Tensor Core 的计算连续性与吞吐量。

    * 稳定性收益：消除超长上下文序列与超深层结构中累积静态偏置引发的隐藏维度数值漂移，增强模型在极端训练环境下的数值稳定性。

## 门控前馈网络与参数缩放法则

### 门控线性单元拓扑与激活函数演进

* **门控线性单元（Gated Linear Unit，GLU）**

    * > **定义**：在前馈网络输入端引入两个并行的线性投影矩阵，使其中一个分支经过非线性激活后作为动态门控信号，与另一分支进行逐元素相乘（Hadamard 积），再经线性投影降维的前馈网络结构。

    * 双矩阵与三矩阵拓扑差异：
      * 标准两层 MLP：输入经单次线性升维后接入非线性激活函数，再经单次线性降维输出，总计包含 $`W_1`$ 与 $`W_2`$ 两个矩阵。
      * GLU 前馈网络：包含门控投影 $`W_{\text{gate}}`$、升维投影 $`W_{\text{up}}`$ 与降维投影 $`W_{\text{down}}`$ 三个权重矩阵。

    * 性能本质：消融实验表明，性能跃迁的核心驱动力来自门控机制（动态特征过滤）本身的存在，具体的非线性激活函数形态仅带来微小差异。

* **Swish 门控线性单元（Swish Gated Linear Unit，SwiGLU）**

    * > **定义**：门控分支采用 Swish（又称 SiLU）作为非线性激活函数的门控线性单元变体。

    * 数学算式：

      $`\displaystyle \text{SwiGLU}(x) = \left( \text{Swish}(x W_{\text{gate}}) \odot (x W_{\text{up}}) \right) W_{\text{down}}`$

      其中 $`\text{Swish}(z) = z \cdot \text{sigmoid}(z)`$。

    * 阵营分布：成为 LLaMA 系列、PaLM、Mistral、Qwen 等现代开源大模型生态的前馈层标配。

* **高斯误差门控线性单元（Gaussian Error Gated Linear Unit，GEGLU）**

    * > **定义**：门控分支采用高斯误差线性单元（GELU）作为非线性激活函数的门控线性单元变体。

    * 数学算式：

      $`\displaystyle \text{GEGLU}(x) = \left( \text{GELU}(x W_{\text{gate}}) \odot (x W_{\text{up}}) \right) W_{\text{down}}`$

      其中 $`\text{GELU}(z) = z \cdot \Phi(z) = z \cdot P(X \le z), X \sim \mathcal{N}(0, 1)`$。

    * 阵营分布：Google 技术体系（T5、Gemma 系列）长期采用的技术路线；与 SwiGLU 表现差异极小。

| MLP 类型                       | 执行顺序                                                                                                                  |
| :----------------------------- | :------------------------------------------------------------------------------------------------------------------------ |
| 标准双矩阵 MLP，ReLU / GELU    | $`x`$ → $`W_1`$ 投影 → 激活函数 $`\sigma`$ → $`W_2`$ 投影 → 输出                                                          |
| 门控三矩阵 MLP，SwiGLU / GEGLU | $`x`$ 同时进入 gate 与 up 两条投影分支；gate 分支经过 $`\sigma`$，与 up 分支逐元素相乘，再经 $`W_{\text{down}}`$ 投影输出 |

### 前馈参数守恒与维度扩展比例

* **三分之二参数对齐法则（Two-Thirds Parameter Preservation Rule）**

    * > **定义**：为了在引入门控机制三矩阵拓扑时，严格保持前馈网络的总参数量与浮点运算量（FLOPs）与传统两矩阵四倍扩展网络守恒，而将中间隐藏维度按原标准缩减至三分之二的维度修正准则。

    * 代数推导：
      * 标准 MLP 参数量：$`P_{\text{standard}} = 2 \times d \times d_{\text{ff}} = 2 \times d \times 4d = 8d^2`$。
      * 门控 GLU 参数量：$`P_{\text{GLU}} = 3 \times d \times d_{\text{ff}}'`$。
      * 令参数守恒：$`3 \times d \times d_{\text{ff}}' = 8d^2 \implies d_{\text{ff}}' = \frac{8}{3}d \approx 2.67d`$。

    * 验证依据：Noam Shazeer 在提出 GLU 变体时通过受控误差棒（Error Bar）实验与 Google T5 架构消融（Narang et al., 2020）共同证实，经过三分之二缩放对齐后的 SwiGLU 在预训练损失与下游任务中一致性优于非门控基线，增益完全来源于架构拓扑而非参数量增加。

* **前馈层扩展比率（FFN Expansion Ratio，$`\alpha_{\text{FFN}}`$）**

    * > **定义**：前馈网络中间隐藏层维度与模型主干隐藏层维度的比值，即 $`\alpha_{\text{FFN}} = \frac{d_{\text{ff}}}{d}`$。

    * 工业界收敛分布：
      * 传统非门控模型：严格收敛于 $`\alpha_{\text{FFN}} \approx 4.0`$（如 GPT-2、GPT-3）。
      * 严格参数对齐的 GLU 模型：严格收敛于 $`\alpha_{\text{GLU}} \approx 2.67`$（即 $`\frac{8}{3}`$）。
      * 较大的 GLU 中间层：部分模型（如 LLaMA 2 70B）约为 $`3.5d`$；具体取值按模型配置，不能推广至整个 LLaMA 系列。

* **前馈参数最优容错盆地（FFN Parameter Flat Basin）**

    * > **定义**：前馈层扩展乘数在较宽的数值范围内，模型验证损失相对于最优解表现出极高容忍度与平缓度的经验参数曲面形态。

    * 盆地范围：神经缩放定律（Kaplan et al., 2020）参数扫描实验证实，前馈乘数在 1 至 10 之间存在极其平坦的低损失盆地，各取值性能差异微弱。

    * 实验边界：课程图中的极端扩展比可能更差，但不能据此宣称大于 10 后损失按二次方增长；须区分特定消融曲线与普遍规律。

    * 极端探索反例：Google T5 初代曾采用 64 倍超大乘数以提升 TPU 矩阵硬件利用率，但因显存与激活值负担过大且 FLOPs 利用效率极低，在 T5 v1.1 中重新回归主流的 2.5 至 2.67 倍标准区间。

## 块级执行时序与层间拓扑结构

### 串行级联拓扑特征

* **串行执行块（Serial Block）**

    * > **定义**：单层 Transformer 内部的多头自注意力子层与前馈网络子层严格按时序先后级联执行的拓扑结构。

    * 数据流公式：

      $`\displaystyle x_1 = x + \text{Attention}(\text{Norm}_1(x)), \quad x_{\text{out}} = x_1 + \text{FFN}(\text{Norm}_2(x_1))`$

    * 硬件执行瓶颈：存在严格的时序依赖链，计算硬件必须等待多头注意力的全部点积与投影计算落盘后，方能启动前馈网络的计算，对底层计算流水线制造了时间维度的等待开销。

* **层级抽象表征能力（Hierarchical Feature Abstraction）**

    * > **定义**：串行拓扑下前馈网络基于经过注意力机制动态汇聚后的上下文特征进行二次非线性组合映射，从而在网络深度方向上逐层递进构建高阶抽象语义的表征特性。

    * 机制保全：串行模式维系了网络的完整有效深度（Effective Depth），每一层网络均完成“上下文动态交互”与“通道级事实特征重组”的交替深化。

### 并行层拓扑与表征深度权衡

* **并行执行块（Parallel Block）**

    * > **定义**：单层 Transformer 内部的多头注意力与前馈网络接收完全相同的归一化输入并并发执行计算，两者的输出增量一次性累加回主干残差流的拓扑结构。

    * 数据流公式：

      $`\displaystyle x_{\text{out}} = x + \text{Attention}(\text{Norm}(x)) + \text{FFN}(\text{Norm}(x))`$

    * 历史沿革：由开源复现模型 GPT-J 推广，Google PaLM 大规模采用，Cohere 早期模型亦有吸纳。

    * 系统收益数值：
      * 两个子模块共享同一次 LayerNorm/RMSNorm，消除一次全量低算术强度访存。
      * 注意力与前馈网络的输入投影矩阵在底层被融合成一个单一的超大 GEMM 矩阵乘法算子。
            * PaLM 论文报告并行块在该实验中提高训练速度约 15%；不能改写为所有模型 MFU 固定提升 15%。

* **有效表征深度损耗（Effective Representation Depth Degradation）**

    * > **定义**：并行拓扑因强制注意力与前馈网络基于相同的上一层输入进行并发变换，使子层之间少了一次串行组合的结构差异；可以讨论较短的计算依赖深度，但不等价于表达能力严格减半。

    * 使用现状：多数所列模型采用串行块，但课程也列出 Command A、Falcon 2 11B、Command R+ 等并行块模型；不能说工业界全线放弃并行结构。

| Transformer 块拓扑     | 数据流与残差关系                                                                        |
| :--------------------- | :-------------------------------------------------------------------------------------- |
| 串行（Serial Block）   | Norm1 → Attention → 第一次残差相加 → Norm2 → FFN → 第二次残差相加；各计算分支有独立跳连 |
| 并行（Parallel Block） | Norm 的输出同时进入 Attention 和 FFN；两条分支与原输入 $`x`$ 相加后输出                 |

## 序列位置依赖与旋转位置编码

### 编码范式演进与内积交叉项缺陷

* **绝对正弦余弦位置编码（Sinusoidal Absolute Positional Encoding）**

    * > **定义**：利用不同频率的正弦与余弦函数为序列每个物理位置计算确定性坐标向量，并直接与词嵌入向量逐元素相加的位置注入方式。

    * 交叉污染项机理：计算词向量 $`x, y`$ 在绝对位置 $`i, j`$ 处的内积展开时产生四个项：

      $`\displaystyle \langle x + p_i, y + p_j \rangle = \langle x, y \rangle + \langle x, p_j \rangle + \langle p_i, y \rangle + \langle p_i, p_j \rangle`$

      中间两项为语义内容向量与绝对物理位置向量的杂交项，破坏了纯粹的相对不变性，允许模型反向解析出绝对物理坐标。

* **可学习绝对位置嵌入（Learned Absolute Positional Embedding）**

    * > **定义**：为序列中每个离散绝对位置索引初始化一个独立的可学习连续向量，并在预训练中随网络联合优化的位置编码方式。

    * 外推硬上限缺陷：退化为离散坐标查找表，同样受内积交叉项污染，且完全丧失外推泛化能力，推理长度不可超越训练设定的最大序列窗口（如 GPT-2、GPT-3）。

* **相对位置偏置（Relative Position Bias）**

    * > **定义**：放弃向量加法注入，直接在自注意力点积打分矩阵上叠加一个仅取决于相对距离标量 $`(i - j)`$ 的偏置矩阵的位置注入机制。

    * 架构代表：T5、Chinchilla 与 ALiBi。

    * 实现权衡：相对偏置在 $`QK^T`$ 上额外相加，可能影响融合与访存，但不取消 GEMM，也不使历史 K/V 失效。ALiBi 等方案可以与 KV cache 和融合注意力内核配合。

* **位置交叉污染项（Positional Cross-terms）**

    * > **定义**：在加法型位置编码方案中，因多项式内积展开而产生的“语义内容与位置向量”、“位置向量与语义内容”之间的非正交混合项。

    * 解决公理：现代方案要求变换函数满足严苛相对约束：

      $`\displaystyle \langle f(x, m), f(y, n) \rangle = g(x, y, m - n)`$

      要求绝对坐标 $`m, n`$ 在内积计算中必须完全抵消。

### 旋转位置编码几何机理与工程实现

* **旋转位置编码（Rotary Position Embedding，RoPE）**

    * > **定义**：通过复数旋转或正交分块对角矩阵，将 Query 向量与 Key 向量按其绝对物理位置在各二维子空间内施加刚性旋转，从而使点积结果自然仅依赖于两向量相对距离的位置编码技术。

    * 相对几何不变性：利用二维旋转矩阵的正交性 $`R(\theta)^T = R(-\theta)`$ 及角度相减性质 $`R(\theta_1)^T R(\theta_2) = R(\theta_2 - \theta_1)`$。

    * 内积相消机理：

      $`\displaystyle \langle R_{\theta, m} x_m, R_{\theta, n} x_n \rangle = x_m^T R_{\theta, m}^T R_{\theta, n} x_n = x_m^T R_{\theta, n - m} x_n`$

      绝对物理索引 $`m`$ 与 $`n`$ 通过三角正交变换对消，保留相对位移 $`n - m`$。

    * 乘法注入属性：位置信息通过旋转矩阵“相乘”施加，彻底消灭了加法位置编码中的多项式交叉污染项。

    * > **易错点**：⚠️ RoPE 仅作用于自注意力计算中的 Query 与 Key 向量，绝对不能施加在 Value 向量上；Value 向量负责传递未失真的语义表征，对其施加旋转将破坏加权求和后的线性重构性质。

* **正交二维子空间分解（Orthogonal 2D Subspace Decomposition）**

    * > **定义**：将 $`d`$ 维的注意力头向量两两配对切分为 $`\frac{d}{2}`$ 个互相正交的二维子空间，并在各个独立二维平面内分别执行角度旋转的高维推广机制。

    * 矩阵构造：

      $`\displaystyle R_{\Theta, m}^d = \text{diag}\left( R(\theta_1 m), R(\theta_2 m), \dots, R(\theta_{d/2} m) \right)`$

      其中每一个 $`R(\theta_k m)`$ 均为二阶标准旋转矩阵。

* **多频基频分布（Multifrequency Base Distribution）**

    * > **定义**：为各个正交二维子空间分配按几何级数递减的基频序列的设计准则。

    * 基频公式：

      $`\displaystyle \theta_i = 10000^{-2(i-1)/d}, \quad i \in \{1, 2, \dots, d/2\}`$

    * 频段物理职能：
      * 高频子空间（$`\theta`$ 极大）：随物理位置推移旋转角度剧烈翻转，对微小相对位移极度敏感，专注于建模相邻词元语法与短语搭配。
      * 低频子空间（$`\theta`$ 极小）：即便跨越数千 Token 旋转角也仅缓慢累积，为长程跨段落上下文依赖提供平滑的全局距离标尺。

    * 高效实现公式：工程上无需实例化稀疏大矩阵，通过交替符号与三角函数按元素相乘实现：

      $`\displaystyle R_{\Theta, m} x = x \odot \cos(m\Theta) + \tilde{x} \odot \sin(m\Theta)`$

      其中 $`\tilde{x} = (-x_2, x_1, -x_4, x_3, \dots, -x_d, x_{d-1})`$。

* **部分旋转位置编码（Partial RoPE）**

    * > **定义**：只对 Q/K 的一部分通道应用旋转，其余通道保留内容特征。具体旋转比例、频率与适用层取决于模型设计。

    * 应用示例：Gemma 4 使用部分通道旋转；部分旋转本身不意味着 KV cache 总维度自动减少。

    * 主流边界：在中大型密集语言模型中，全维度标准 RoPE 仍居统治地位。

**RoPE 二维子空间旋转**：坐标原点为 $`(0,0)`$，两个位置向量分别旋转 $`n\theta`$ 与 $`m\theta`$，相对夹角为 $`(n-m)\theta`$。旋转保持向量长度不变。

## 宏观架构超参数与分布式并行工程

### 几何纵横比与分布式并行博弈

* **模型纵横比（Aspect Ratio，$`d / L`$）**

    * > **定义**：模型主干隐藏层维度 $`d`$ 与网络总层数 $`L`$ 的比值，用于定量刻画模型在几何形态上偏向“宽而浅”还是“深而窄”。

    * 经验范围：课程列出的模型纵横比并不统一，许多在 100~200 左右，也有明显例外；下式仅为一个粗略量级：

      $`\displaystyle \frac{d}{L} \approx 100`$

      例如 40 层模型其主干隐藏层宽度普遍设定在 4096 附近。

    * 算法与硬件权衡平衡点：
      * 纯理论表达角度：增加深度 $`L`$ 有利于构建复杂的层次化非线性特征抽象。
      * 分布式系统角度：深度方向拆分极其复杂且效率低下，宽度方向横向切分则高度适配规整的硬件通信拓扑。

    * 决定性驱动力：架构消融研究表明，在固定的总计算量（FLOPs）预算下，总 FLOPs 是主导模型性能的最核心变量；在纵横比 100 附近宽阔的安全盆地内，超参数设定必须优先倒向底层硬件吞吐与分布式并行效率。

* **流水线并行与气泡损耗（Pipeline Parallelism & Bubbles）**

    * > **定义**：在超深模型（$`L`$ 极大，纵横比远小于 100）无法单卡容纳时，沿层数深度方向将不同层分配至不同 GPU 节点进行级联串行推进的分布式并行策略。

    * 系统缺陷：引入跨节点长距离激活值通信，更致命的是在流水线填充（Fill）与排空（Drain）阶段不可避免地造成大量计算硬件的空置等待，产生严重的“流水线气泡（Pipeline Bubble）”。

* **张量并行（Tensor Parallelism，TP）**

    * > **定义**：在较宽模型（$`d`$ 较大，纵横比适中或偏大）中，将单层内部的权重矩阵按行或按列规整切分到单机内多个 GPU 上协同计算的并行范式。

    * 系统优势：依托单机内部的高速互联总线（如 NVLink），张量并行仅需在算子内部执行规整的高带宽 All-Reduce 规约，调度逻辑简单且完全不存在时间线上的流水线气泡。

| 网络形态                                | 并行策略      | 原示意中的工程取舍                                   |
| :-------------------------------------- | :------------ | :--------------------------------------------------- |
| 极深网络，$`L`$ 很大、$`d/L\ll100`$     | 流水线并行 PP | 跨节点通信与时间线气泡，需要控制流水线开销           |
| 较宽网络，$`d`$ 很大、$`d/L\approx100`$ | 张量并行 TP   | 利用单机 NVLink 切分计算；实际通信与气泡仍取决于调度 |

### 注意力头维度匹配与词表度量对偶

* **注意力头维度对称约束（Head Dimension Symmetry Constraint）**

    * > **定义**：许多 MHA 配置采用 $`h d_k=d`$，但 Q/K/V 投影输出宽度可以独立于残差宽度设置；这不是数学上必须满足的守恒约束。

    * 守恒代数式：

      $`\displaystyle \rho_{\text{head}}=\frac{h d_k}{d};\quad h d_k=d\text{ 是常见配置，非硬性要求}`$

      其中 $`h`$ 为注意力头数，$`d_k`$ 为单头特征维度。

    * 配置例外：64、128 是常见头维度，但也有 256 等值。PaLM 540B 的 48 个 Query 头、256 维头宽和 18432 维模型宽度给出 $`48\times256/18432=2/3`$。

    * **原课件勘误**：[lecture_03.pdf，第 43 页](https://github.com/stanford-cs336/lectures/blob/de53a9f979a6ee35f7d13a5e1aadee5ea1afc58e/lecture_03.pdf#page=43) 将 PaLM 540B 的头宽和比值写为 258、1.48；正确值为 256、$`48\times256/18432=2/3`$。

* **词汇表规模扩容（Vocabulary Size Expansion）**

    * > **定义**：模型输入与输出投影层所涵盖的离散 Token 总容量随代际演进大幅增长的架构趋势。

    * 代际分水岭：
      * 早期单语模型：词表大小 $`V \approx 32{,}000`$（32k），仅覆盖英文及极少通用符号。
      * 现代多语言生产模型：词表大小扩充至 $`100{,}000 \sim 256{,}000`$（100k~256k，如 LLaMA 3 采用 128k）。

    * 驱动力量：多语言与代码高密度压缩需求，大词表显著降低多语言切分碎片率并缩短物理序列长度；模型参数规模扩展使词表投影参数占比稀释。

* **每字节比特数（Bits Per Byte，BPB）**

    * > **定义**：语言模型在预测测试集文本时，平均无损压缩每个原始字符字节所需的二进制信息量（比特数），是跨分词器模型评估的统一客观标准。

    * 数学算式：

      $`\displaystyle \text{BPB} = \frac{\mathcal{L}_{\text{total}}}{N_{\text{bytes}} \cdot \ln 2}`$

      其中 $`\mathcal{L}_{\text{total}}`$ 为模型在整个测试集文本上的总负对数似然损失，$`N_{\text{bytes}}`$ 为原始输入文本未经切分时的 UTF-8 原始总字节数。

    * > **易错点**：⚠️ 基于 Token 的困惑度绝对不能用于跨不同分词器的模型对比；不同分词器的切分粒度与压缩比不同，直接比较其 Token 级别的交叉熵损失无物理意义，必须统一换算为以原始字节为基准的每字节比特数。

## 预训练正则化机制与优化动力学

### 单遍遍历与无过拟合现象

* **单遍数据流遍历（Single-Pass Pretraining）**

    * > **定义**：在大规模预训练中，海量网络语料总规模远超物理算力预算，使得优化器在整个训练周期内对语料库仅进行单次遍历（Single-Epoch）的数据吞吐模式。

    * 泛化边界：大规模单遍预训练可能呈现很小的训练/验证损失差距，但单遍不保证无记忆或无过拟合；数据重复、分布偏差与模型容量仍会影响泛化。

* **随机失活弃用（Dropout Deprecation）**

    * > **定义**：许多现代大模型预训练配方采用 $`p=0`$；这是一种常见选择，并非全部模型必须遵循的规范（课程所列 OPT、早期 Qwen 等有非零 Dropout）。

    * 使用权衡：在课程讨论的大数据配方中，Dropout 未必带来收益，故常省略；不能据此断言它必然破坏 Adam 统计或所有单遍训练都不应使用。

### 权重衰减与优化器几何调节协同

* **权重衰减优化器协同（Weight Decay Optimizer Synergy）**

    * > **定义**：在预训练中，权重衰减的作用从传统的防止过拟合正则化工具，演变为主动调控权重模长动态、协助优化器高效收敛的几何调节手段。

    * 学习率退火联动机制：强权重衰减在训练初期由于向原点收缩约束导致损失下降略慢；但当训练进入后期学习率逐步衰减（LR Annealing）阶段，权重衰减持续抑制参数范数的无界扩张，维持了各层网络的有效学习率，协助优化器逃离尖锐局部极小值，最终收敛至泛化表现更优的平坦盆地。

    * > **易错点**：⚠️ 在海量语料单遍预训练中，绝不能将权重衰减简单视作防止过拟合的 $`L_2`$ 惩罚项；它必须与动态学习率退火调度协同推进才能发挥调控权重范数与逃离尖锐极值的作用，固定学习率下单用无显著收益。

* **有效学习率维持（Effective Learning Rate Maintenance）**

    * > **定义**：通过权重衰减施加向心收缩力限制权重张量模长 $`\|W\|`$，从而使得参数更新量 $`\Delta W`$ 与权重基数 $`\|W\|`$ 的相对步长保持在稳定充沛区间的机理。

    * 动力学效应：若没有权重衰减约束，权重范数会在数百万步迭代中持续单调递增，导致固定学习率下的实际相对更新步长不断衰竭，使模型过早陷入鞍点停滞。

## 训练稳定性干预与数值极值防御

### 输出端配分函数漂移与 Z-loss 正则化

* **配分函数数值发散（Partition Function Instability）**

    * > **定义**：在输出端 Softmax 映射至十万级词表的过程中，所有 logits 经指数运算累加后的配分函数 $`Z = \sum_{j=1}^V \exp(u_j)`$ 在长期训练中发生无界膨胀或急剧收缩，引发对数似然 $`\log Z`$ 溢出或下溢的数值崩溃现象。

* **配分函数对数平方正则化（Z-loss Regularization）**

    * > **定义**：在主交叉熵损失之外，显式追加一项对对数配分函数偏离零进行二次惩罚的辅助损失算子。

    * 数学算式：

      $`\displaystyle \mathcal{L}_{\text{total}} = \mathcal{L}_{\text{CE}} + \alpha \cdot (\log Z)^2`$

      其中 $`\alpha`$ 为微小的惩罚系数（通常设定为 $`10^{-4}`$ 量级）。

    * 调控机理：利用二次罚函数在 $`\log Z`$ 偏离 0 时产生强烈的回拉梯度，迫使网络主动平移输出 logits，鼓励 $`\log Z`$ 接近 0，降低 logits 的绝对尺度漂移；有限惩罚不保证 $`Z=1`$，也不根除所有数值错误。

    * 工业部署：被 Google PaLM 率先引入，并成为 OLMo、DCLM 等现代开源大模型的标配防线。

* **Softmax 平移不变性（Softmax Shift Invariance）**

    * > **定义**：对输入 logits 向量同时加上或减去任意标量常数 $`c`$，Softmax 输出的离散概率分布严格恒定不变的数学性质。

    * 系统含义：输出概率形态仅由 logits 间的相对差值决定，因此通过 Z-loss 人为约束配分函数绝对大小不会扭曲预测分布，在理想的统一平移下不改变 Softmax；实际添加正则项会改变共享参数的训练梯度，不能保证零任务性能代价。

### 注意力内部尺度控制与极值截断方案

* **注意力退化（Attention Collapse）**

    * > **定义**：在深层网络中，未经直接约束的 Query 与 Key 投影矩阵范数发生无界漂移，导致点积打分 $`\frac{Q K^T}{\sqrt{d_k}}`$ 极差过大，Softmax 输出急剧退化为近乎 One-Hot 尖锐分布并诱发剧烈梯度尖峰的现象。

* **注意力查询与键归一化（Query-Key Normalization，QK-Norm）**

    * > **定义**：在每个注意力头内部，将 Query 向量与 Key 向量送入点积矩阵乘法之前，分别独立施加无偏置 RMSNorm 的内部稳定性干预手段。

    * 数学算式：

      $`\displaystyle \tilde{Q} = \text{RMSNorm}(Q), \quad \tilde{K} = \text{RMSNorm}(K), \quad \text{Attn\_Scores} = \frac{\tilde{Q} \tilde{K}^T}{\sqrt{d_k}}`$

    * 稳定机理：RMSNorm 约束均方根；无可学习缩放且忽略 epsilon 时向量的 L2 范数为 $`\sqrt{d_k}`$，并非 1。可学习缩放仍会改变幅度，QK-Norm 可改善稳定性但不是消除退化的保证。

    * 技术发源：最早诞生于图文多模态领域（Idefics、Chameleon 等），因多模态特征动态范围极大而必须依赖该算子稳定训练，随后被纯文本主流大模型全面采纳为标准配置。

* **对数几率软截断（Logit Soft-Capping）**

    * > **定义**：在点积打分输入 Softmax 之前，利用双曲正切函数（$`\tanh`$）对原始 logits 施加显式刚性区间压缩的非线性截断机制。

    * 数学算式：

      $`\displaystyle \text{logits}_{\text{capped}} = C \cdot \tanh\left(\frac{\text{logits}}{C}\right)`$

      其中 $`C`$ 为固定阈值上限（Gemma 2 的注意力 logits 为 50，最终输出 logits 为 30）。

    * 权衡：soft-capping 限制输入 Softmax 的 logits，但可能改变梯度和表达；QK-Norm 同样改变模型。两者效果需按配方验证，不能断言前者必降精度或后者无损。

| 注意力数值稳定方案 | 计算顺序                                            | 作用                                    |
| :----------------- | :-------------------------------------------------- | :-------------------------------------- |
| QK-Norm            | Q、K → RMSNorm → $`QK^T/\sqrt d`$ → Softmax         | 从源头约束向量模长                      |
| Logit Soft-Capping | Q、K → $`QK^T/\sqrt d`$ → $`C\tanh(x/C)`$ → Softmax | 限制 logit 幅度，高置信区域梯度受到压缩 |

## 推理内存墙与轻量化注意力设计

### 自回归解码与键值缓存访存瓶颈

* **键值缓存（Key-Value Cache，KV Cache）**

    * > **定义**：在自回归因果解码过程中，将历史所有步骤生成的 Key 向量与 Value 向量持久化保存在 GPU 显存中，以避免在每个新 Token 预测步中重复计算历史投影的显存复用技术。

    * 计算量节省：将时间复杂度从 $`\mathcal{O}(N^2)`$ 的重复矩阵计算降为当前步的单向量点积更新。

* **解码端内存带宽瓶颈（Decoding Memory-Bandwidth Bound）**

    * > **定义**：自回归生成阶段因每步仅预测单个 Token，GPU 必须在每次迭代中将全量模型权重与历史全量 KV 缓存从 HBM 完整加载至片上 SRAM，导致计算核心因严重缺数而大幅空转的硬件瓶颈状态。

    * 算术强度断崖：预填充（Prefill）阶段序列完整已知，处于高算术强度的计算受限（Compute-Bound）状态；而在增量解码阶段，算术强度表达式为：

      $`\displaystyle \text{Arithmetic Intensity}_{\text{decode}} \propto \frac{1}{\frac{N}{d} + \frac{1}{B}}`$

      其中 $`N`$ 为上下文长度，$`d`$ 为模型维度，$`B`$ 为批次大小。长上下文下 $`\frac{N}{d}`$ 占据绝对主导，算术强度暴跌，系统彻底受制于显存带宽墙。

### 键值共享注意力拓扑演进

* **多查询注意力（Multi-Query Attention，MQA）**

    * > **定义**：保留所有 $`h`$ 个独立的 Query 投影头，但在全模型单层内强制所有 Query 头完全共享单一一组 Key 头和 Value 头的极端轻量化注意力结构。

    * 显存缩减幅度：KV Cache 的显存占用与每步搬运带宽直接被压缩至传统 MHA 的 $`\frac{1}{h}`$（在 32 头模型中显存占用下降约 96.8%）。

    * 缺陷代价：强制多头共享同一套键值语义空间，严重损害了模型在捕捉不同子空间关联时的表达容量，导致下游复杂任务准确率明显下滑。

* **分组查询注意力（Grouped-Query Attention，GQA）**

    * > **定义**：将 $`h`$ 个独立的 Query 头划分为 $`G`$ 个互不相交的组，组内多个 Query 头共享该组专属的单个 Key 头与 Value 头的折中注意力拓扑。

    * 退化边界条件：
      * 当 $`G = h`$ 时，退化为经典的多头自注意力（MHA）。
      * 当 $`G = 1`$ 时，退化为极端的多查询注意力（MQA）。
      * 当 $`1 \lt  G \lt  h`$ 时（典型配置如 8:1 或 4:1），构成黄金平衡点。

    * 帕累托最优（Pareto Frontier）：实证表明，通过仅保留 8 个 KV 组，GQA 成功将推理 KV Cache 带宽与显存消耗削减 75% 至 87.5%，同时下游任务基准表现几乎与 MHA 完全重合，已成为 LLaMA 2/3、Mistral 等全行业主流大模型的绝对共识。

* **多头潜在注意力（Multi-Head Latent Attention，MLA）**

    * > **定义**：通过低秩压缩投影矩阵将 Key 与 Value 向量在持久化显存中压缩为一个极低维度的隐空间潜在向量（Latent Vector），并在计算时动态投影解压的更前沿轻量化注意力范式。

    * 架构代表：DeepSeek-V2，在不损失独立多头建模自由度的前提下，实现了比 GQA 更极致的 KV 缓存物理显存压缩。

以 8 个 Query 头为例：

| 拓扑      | Query 分组                                   | Key / Value 缓存份数 | 相对 KV 缓存占用 |
| :-------- | :------------------------------------------- | :------------------- | ---------------: |
| MHA       | Q0–Q7 各自使用 K0–K7、V0–V7                  | 各 8 份              | 100%             |
| GQA，4 组 | Q0/Q1、Q2/Q3、Q4/Q5、Q6/Q7；每组共享一对 K/V | 各 4 份              | 50%              |
| MQA       | Q0–Q7 全部共享 K0、V0                        | 各 1 份              | 12.5%            |

### 超长上下文稀疏混合注意力架构

* **滑动窗口注意力（Sliding Window Attention，SWA）**

    * > **定义**：限制每个 Token 仅能关注其前面固定物理窗口大小 $`W`$ 内的邻近 Token、屏蔽窗口之外远端位置的局部稀疏注意力机制。

    * 复杂度：固定头宽时，单层训练/Prefill 注意力计算由 $`O(S^2)`$ 降至 $`O(SW)`$；解码时普通全注意力 KV cache 是 $`O(S)`$，滑动窗口且及时淘汰旧 KV 时为 $`O(W)`$。KV cache 从来不是 $`O(S^2)`$。

    * 独立缺陷：若全网络均采用 SWA，模型彻底失去在远距离进行单步直接精确寻址的能力。

* **局部与全局交替混合拓扑（Hybrid Local-Global Attention Topology）**

    * > **定义**：在超深网络中，大部分层采用廉价的局部滑动窗口注意力，周期性地间隔插入少量全局密集全注意力（Dense Full Attention）的混合堆叠架构。

    * 典型堆叠周期：例如 Cohere Command A 及 Llama 系列长上下文版本采用的 3:1 周期模式——每连续 4 层网络中，前 3 层挂载低显存的局部滑动窗口注意力，第 4 层挂载全尺寸密集全局注意力。

    * 信息上浮机理：浅层局部 SWA 以极低开销抽取局部短语语法，信息随残差流向上逐层传递并自然扩大感受野；周期性全局全注意力层充当全序列长程信息交互中枢，从而以极低的全局 KV Cache 代价维系了百万级上下文的直接长程召回。

* **跨机制交替混合拓扑（Cross-Mechanism Hybrid Topology）**

    * > **定义**：将全自注意力层与非 Transformer 线性序列模型（如状态空间模型 SSM）按固定比例周期性交错混合堆叠的演进架构。

    * 代表探索：课程当前列出的 Qwen 3.5 / Qwen3-Next 交替使用 Gated DeltaNet 与全注意力；Qwen 2.5 不能作为这一混合架构的例子。Gated DeltaNet 属于门控线性注意力，可用递归状态实现，但不应与 Mamba 等 SSM 混为一类。

## 现代密集 Transformer 核心架构决策对比

下表是常见选择与边界；具体模型以论文和配置为准，不能把模型家族视为统一实现。

| 维度       | 常见选择                                       | 需要保留的边界                                                                         |
| :--------- | :--------------------------------------------- | :------------------------------------------------------------------------------------- |
| 归一化位置 | Pre-Norm；也有分支输出归一化或双重归一化       | 原始 Transformer 是 Post-Norm，GPT-3 使用 Pre-Norm；T5 也不能列作 Post-Norm 基线       |
| 归一化算子 | LayerNorm 或 RMSNorm                           | RMSNorm 可减少操作，但效果、速度与访存次数依赖实现                                     |
| 偏置与门控 | 部分模型去偏置，SwiGLU/GEGLU 广泛采用          | 早期 Qwen 存在 QKV 偏置；门控不保证固定精度增益                                        |
| FFN 宽度   | 非门控常取 $`4d`$；门控参数对齐基准为 $`8d/3`$ | Gemma 等有更大扩展比；参数对齐不等于所有非矩阵操作 FLOPs 严格相等                      |
| 执行时序   | 串行较常见，也有并行块                         | PaLM 等并行块的加速是特定实现结果，表达能力不能简单除以二                              |
| 位置编码   | RoPE、相对偏置、可学习绝对位置等               | 部分 RoPE 不自动压缩 KV；相对偏置可配合 GEMM 与缓存                                    |
| 几何尺寸   | 系统与验证损失共同决定宽深比、头宽             | $`d/L\approx100`$、$`hd_k=d`$ 是常见例子而非硬性定律                                   |
| 词表与评估 | 词表按语言与数据设计；可用 BPB 比较            | 同一原始测试文本与编码口径是 BPB 可比的前提，BPB 也不是唯一任务指标                    |
| 正则化     | 很多配方省略 Dropout 并保留权重衰减            | 单遍训练不保证零泛化差距，其他配方仍可使用 Dropout                                     |
| 数值稳定   | Z-loss、QK-Norm、soft-capping 等               | 都不是零风险保证；Gemma 2 的 attention/output cap 分别为 50/30                         |
| KV 压缩    | MQA、GQA、MLA                                  | 质量与带宽收益依赖头数、实现、上下文和训练配方                                         |
| 长上下文   | SWA/全注意力或线性注意力/全注意力交替          | 固定窗口 SWA 的计算为 $`O(SW)`$，滚动 KV 为 $`O(W)`$；Qwen 3.5/Next 与 Qwen 2.5 应区分 |
